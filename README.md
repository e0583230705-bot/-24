# ביקורת חכמה — כלי עבודה לביקורת דוחות כספיים (שם עבודה)

מערכת למשרדי רואי חשבון: קולטת את ספרי הלקוח המבוקר ואת נתוני השכר שלו, מריצה את הבדיקות שרואה חשבון עושה
היום ידנית, ומרכזת את הממצאים עם תיעוד ההסבר לכל אחד. **שיקול הדעת וחוות הדעת נשארים אצל רואה החשבון המבקר**:
רק רואה חשבון מוסמך ובלתי תלוי רשאי לחתום על חוות דעת, ואין לזה עקיפה.

> ⚠️ **שלב פיתוח.** הפרמטרים המקצועיים (שיעורי ביטוח לאומי, שכר מינימום, פנסיה, ספים) נאספו ממקורות משניים
> ודורשים אימות של רואה חשבון לפני הסתמכות. עד כה הכול נבדק על קבצים שנבנו לפי המפרטים הרשמיים, לא על קבצים
> אמיתיים.

## מה המערכת עושה

**תיק ביקורת** לכל לקוח מבוקר ושנת דוח, בתוך המשרד, עם הפרדה מלאה בין משרדים; צוות עם הרשאות (בעלים / רואה
חשבון / צפייה); כניסה מאובטחת ואיפוס סיסמה במייל.

### ספרי הלקוח
- **קליטת קובץ במבנה אחיד** (BKMVDATA.TXT + INI.TXT, לפי הוראות רשות המסים 1.31) מכל תוכנה רשומה, כולל זיהוי קידוד
  ובדיקות שלמות לקובץ (מספור רשומות, רשומת סגירה, סיכומי INI, התאמה בין אינדקס החשבונות לתנועות, מספר עוסק שונה
  מהלקוח בתיק). אפשר גם כרטסת CSV. אזהרה כשנקלט קובץ של שנה אחרת.
- **מאזן בוחן** ואיתור פקודות לא מאוזנות.
- **מהותיות** כוללת / לביצוע / זניחה.
- **בדיקת פקודות יומן**: שבת, סכום עגול, סמוך לסוף השנה / אחריו, בלי תיאור, מעל המהותיות, כפולות.
- **חוק בנפורד** (ספרה ראשונה, ספי Nigrini).
- **סקירה אנליטית**: קליטת השנה הקודמת, השוואת יתרות לפי חשבון או לפי קבוצה במאזן, סימון שינויים שגם מעל
  המהותיות לביצוע וגם מעל 10%, חשבונות חדשים / שנסגרו, חודשים חריגים. לכל ממצא הסבר מתועד (מי, מתי) ומונה "הוסברו".
- **התאמת בנק**: דף בנק (CSV) מול חשבון הבנק בספרים, פריטים פתוחים (כולל צ'קים שנפרעו אחרי סוף השנה כראיה),
  תנועות בבנק שלא נרשמו, הפרש לא מוסבר, יתרה לפי אישור בנק.
- **סבירות מע"מ עסקאות** לפי חודש, עם הצעה אוטומטית של החשבונות.
- **מדגם כספי (MUS)** שניתן לשחזור לפי seed.

### ביקורת שכר
- **קובץ 126** (הדיווח השנתי לרשות המסים) לפי המפרט הרשמי לשנת 2025 — רשומות 10/20/30/40/50 — עם בדיקות השלמות
  המובנות בקובץ (צבירות רשומות העובדים מול רשומות הסיכום, והתאמה 126 ↔ 12 דיווחי 102).
- **ממצאים על נתוני השכר**: ת.ז. לא תקינה או כפולה, שכר ללא ניכויים, עובד ותיק ללא פנסיה, תשלום לעובד שעזב, תאריכים
  לא עקביים, שכר חריג, חודשים חריגים, קפיצות במספר העובדים.
- **שכר ↔ ספרים**: ברוטו, ב"ל מעביד, הפרשות סוציאליות, מס ניכויים וב"ל לשלם מול חשבונות הספרים (מיפוי אוטומטי לפי
  שמות + תיקון ידני), כולל יתרות 31.12 מול חוב דצמבר.
- **ריכוז שכר חודשי (אקסל / CSV)** מכל תוכנת שכר: זיהוי העמודות לפי הכותרות ומיפוי ידני שנשמר; בדיקות בתוך התלוש
  (נטו, שכר מינימום, שעות נוספות, ב"ל עובד, פנסיה, סכומים שליליים), לאורך השנה לעובד (כפילויות, תשלום אחרי סיום,
  קפיצות, נטו עגול), בין עובדים (חשבון בנק משותף), ומול 126 (לכל חודש מול 102, לכל עובד).

## ארכיטקטורה

```
src/
  lib/domain/ledger/   ← ספרים: מבנה אחיד, מאזן בוחן, פקודות, בנפורד, מהותיות, מדגם, אנליטיקה, התאמות
  lib/domain/payroll/  ← שכר: קובץ 126 (טבלאות השדות מהמפרט), ריכוז שכר, בדיקות, התאמה לספרים, פרמטרים
  lib/services/        ← שכבת נתונים: כל פונקציה מקבלת מזהה משרד ואוכפת הפרדה בין משרדים
  db/                  ← סכמת Postgres (Drizzle). סכומים באגורות
  app/                 ← ממשק (Next.js, עברית RTL) ו־Server Actions עם ולידציה (Zod)
docs/research/         ← המחקר שעליו נשענות הבדיקות, כולל המפרט הרשמי של קובץ 126
```

בפיתוח ובבדיקות ה־DB הוא PGlite (Postgres בתוך התהליך). בייצור: Supabase (או כל Postgres) דרך `DATABASE_URL`.
הסכמה כוללת גם טבלאות של מערכת הנהלת החשבונות שממנה הפרויקט הופרד; הן אינן בשימוש כאן ונשארו כדי לא לשבור
מסדי נתונים קיימים.

## הרצה

```bash
npm install
npm run dev        # http://localhost:3000
npm test
npm run typecheck
npm run lint
```

הגדרות סביבה: `.env.example` → `.env.local`. שינוי בסכמה: `src/db/schema.ts` ואז `npm run db:generate`.

### העלאה ל־Netlify

`DATABASE_URL` (Supabase) + `DATABASE_MIGRATIONS=external` + `APP_URL`. הסכמה מנוהלת ב־Supabase (ראו `docs/HANDOFF.md`). גודל בקשה מוגבל ל־6MB.

## מפת דרכים

1. הפרשות סוף שנה (חופשה, הבראה, פיצויים) מול המאזן; מס"ב ↔ נטו.
2. ניירות עבודה: מה נבדק, מה נמצא, מי הכין, מי אישר, סטטוס לכל תחום.
3. טיוטת מכתב הערות להנהלה מכל הממצאים.
4. השוואה לדיווחי המע"מ בפועל (PCN874).
5. סעיפים נוספים בדוח, אחד אחרי השני, לעומק.
