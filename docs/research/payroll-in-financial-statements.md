## 1. איפה השכר מופיע

**דוח רווח והפסד:** בישראל השכר **לא שורה נפרדת** (למעט מלכ"רים ובנקים); מפוזר לפי פונקציה ונחשף בביאורים:

| הנהלה וכלליות | "משכורות ונלוות" |

**ביאור הוצאות שכר ונלוות** ⚠: שכר ומשכורות; ב"ל מעביד; הפרשות סוציאליות (תגמולים, פיצויים, השתלמות); הוצאות
(הכנסות) בגין הטבות לאחר סיום העסקה (רק בלי סעיף 14); חופשה והבראה; תשלום מבוסס מניות; הטבות אחרות.

**מאזן:**
- שוטף: "עובדים ומוסדות בגין שכר" (נטו לתשלום, מס הכנסה ניכויים, ב"ל, קופות); "הפרשה לחופשה והבראה";
  "הפרשה למענקים".
- לא שוטף: "התחייבויות בשל הטבות לעובדים, נטו" = התחייבות לפיצויים **בניכוי** "יעודה לפיצויים" / נכסי תוכנית.
- עמותות (תקן 5 / ג"ד 69): השכר **כן** שורה נפרדת ("שכר ונלוות") בעלות הפעילויות ובהנהלה וכלליות.

## 2. אינדקס חשבונות טיפוסי

**אומת (ריווחית):** קודי מיון 231 שכר, 232 ביטוח לאומי, 233 גמל.
**חשבשבת / פריוריטי** ⚠: אין אינדקס מספרי מחייב; מה שחשוב לקוד הוא **קוד המיון / סוג הכרטיס** (תוצאתי ↔
מאזני) + מילות מפתח בשם, עם מיפוי ידני.

- **הוצאה:** הוצאות שכר / משכורות / שכר עבודה (לפי מחלקה); ביטוח לאומי מעביד; הפרשות סוציאליות / גמל / פנסיה
  מעביד / פיצויים / קרן השתלמות מעביד; הבראה; חופשה; שווי; מס שכר (מלכ"ר); היטל עובדים זרים.
- **התחייבות:** עובדים — נטו לתשלום; מס הכנסה ניכויים; ביטוח לאומי לשלם; קופות לשלם; הפרשה לחופשה; הפרשה
  להבראה; הפרשה למענקים; התחייבות לפיצויים; ניכויים אחרים (עיקולים, ועד).
- **נכס:** יעודה לפיצויים; הלוואות / מקדמות לעובדים.

**פקודת השכר:**
```
ח' הוצאות שכר (ברוטו)                          ← ריכוז: סה"כ ברוטו
ח' ביטוח לאומי מעביד                           ← עלות מעביד: ב"ל מעסיק
ח' הפרשות סוציאליות (פנסיה/פיצויים/קה"ש מעביד)   ← עלות מעביד: הפרשות
    ז' עובדים — נטו לתשלום
    ז' מס הכנסה ניכויים
    ז' ביטוח לאומי לשלם (עובד + מעביד + בריאות)
    ז' קופות לשלם (עובד + מעביד)
    ז' ניכויים אחרים
```
**זהות:** ברוטו + הפרשות מעביד + ב"ל מעביד = נטו + כל הניכויים + כל ההעברות למוסדות = עלות מעביד.

## 3. "דוח עלות מעביד" / "ריכוז שכר" — הגשר להנה"ח ⚠

כל התוכנות מפיקות ריכוז חודשי/שנתי + קובץ "פקודת שכר" / ממשק הנה"ח (למשל movein של חשבשבת). בלוקים:
- **תשלומים:** יסוד, ש"נ, פרמיות, מענקים, הבראה, חופשה/פדיון, מחלה, נסיעות, שווי, החזרים, פיצויים ששולמו →
  **ברוטו**; וגם **ברוטו למס**, **ברוטו לב"ל**, **שכר קובע לפנסיה**.
- **ניכויי חובה:** מס, ב"ל עובד, בריאות.
- **ניכויי רשות / קופות עובד:** פנסיה, השתלמות, הלוואות, מקדמות, עיקולים, ועד → **סה"כ ניכויים**, **נטו**.
- **הפרשות מעסיק:** ב"ל מעסיק, תגמולים 6.5%, פיצויים 8.33%/6%, השתלמות 7.5%, א.כ.ע., מס שכר, היטל → **סה"כ
  הפרשות**, **עלות מעביד** (ברוטו + הפרשות; בד"כ 20–35% מעל הברוטו).
- **צבירות:** חופשה (פתיחה, צבירה, ניצול, יתרה, שווי), מחלה, ותק, מספר עובדים/משרות.

## 4. תקן חשבונאות ישראלי 39 "הטבות עובד" — מה המבקר בודק

אומת: פורסם 8/2017, מבוסס IAS 19 עם פישוטים; תחולה מ־1.1.2018; החליף ג"ד 19 (חופשה) ו־20 (פיצויים). ארבע
קטגוריות: זמן קצר, לאחר סיום העסקה, זמן ארוך אחר, פיטורין. הטבות לזמן קצר — לא מהוון.

יישום ⚠:
1. **חופשה:** הפרשה = יתרת ימים צבורים × שכר יומי עדכני (+ נלוות). בדיקה: דוח צבירה מתוכנת השכר ליום המאזן ↔
   כרטיס ההפרשה; התנועה = ההוצאה.
2. **הבראה:** הפרשה יחסית לחודשים שנצברו מאז התשלום האחרון (בד"כ יוני/יולי → בדצמבר ~6 חודשים).
3. **בונוסים:** רק עם מחויבות ואומדן מהימן; לבדוק הסכמים, החלטות, תשלומים אחרי המאזן.
4. **פיצויים:**
   - **סעיף 14 מלא:** תוכנית להפקדה מוגדרת → ההוצאה = ההפקדה; **אין התחייבות ואין יעודה**. בדיקה: הפקדות ↔
     8.33% × שכר קובע ↔ אישורי קופות.
   - **ללא סעיף 14:** הטבה מוגדרת → התחייבות = שכר אחרון × שנות ותק, בניכוי יעודה. IAS 19 דורש אקטואריה;
     ישויות קטנות רבות משתמשות ב"שכר אחרון × ותק" — **זה בדיוק מה שרו"ח צריך לאשר**.
   - ביאור: תנועה בהתחייבות וביעודה, הפרדה בין סעיף 14 ללא.
5. **זמן ארוך אחר** (מענקי יובל): מהוון.

## 5. מפת ההתאמה "שכר ↔ ספרים" (לפיתוח)

**קלט A — ספרים:** זיהוי כרטיסים לפי סוג (תוצאתי/מאזני) + מילות מפתח: שכר|משכורת|עבודה · ביטוח לאומי|ב"ל ·
גמל|פנסיה|פיצויים|השתלמות|סוציאלי · מס הכנסה ניכויים|ניכויים · עובדים|נטו|משכורות לשלם · חופשה|הבראה|מענק ·
יעודה|עתודה|התחייבות לפיצויים|סיום יחסי.

**קלט B — ריכוז שכר ו/או 126 צד א' + 12 × 102.**

| סכום בדוח השכר | כרטיס/י GL | בדיקה |
|---|---|---|
| ברוטו (12 חודשים) | ח' כל כרטיסי הוצאות שכר | שווה; הפרשים מוסברים: שווי, הפרשות חופשה/הבראה/בונוס, היוון שכר, פיצויים דרך קופה |
| ב"ל מעסיק (126 שדה 15) | ח' ביטוח לאומי מעביד | שווה (±עיגול) |
| הפרשות מעסיק | ח' הפרשות סוציאליות | שווה; הפרש → ללא סעיף 14 / שינוי בהתחייבות |
| עלות מעביד | סך חובה בפקודות השכר | שווה |
| נטו (חודשי) | ז' עובדים נטו ↔ בנק | יתרת סוף שנה = נטו דצמבר |
| מס הכנסה (126 טור ב') | ז' מס הכנסה ניכויים | יתרה = חודש אחד; תנועה שנתית = 126 |
| ב"ל (126 טור ו') | ז' ביטוח לאומי לשלם | יתרה = חודש אחד; תשלומי בנק = 102 |
| קופות עובד+מעסיק | ז' קופות לשלם | יתרה ≈ חודש; פיגור > חודש = ממצא |
| 126 טור ד' ↔ "ברוטו למס" | — | שווה; 126 = Σ102 |
| צבירת חופשה × שכר יומי | הפרשה לחופשה | סבירות |
| ימי הבראה × תעריף × חודשים | הפרשה להבראה | סבירות |
| ללא סעיף 14: שכר אחרון × ותק | התחייבות − יעודה | = "התחייבות בשל סיום יחסי עובד־מעביד, נטו" |
| מספר עובדים לפי חודש | — | עלות ממוצעת לעובד; שינוי חודשי חריג |

**אנליטיקה:** ב"ל מעביד / ברוטו ≈ 4.5%–7.6% משוקלל; הפרשות / ברוטו ≈ 14.8%–22.3%; חודשים גבוהים (הבראה,
בונוסים) גלויים גם ב־126 צד א'; שכר דצמבר ↔ יתרות זכאים.
